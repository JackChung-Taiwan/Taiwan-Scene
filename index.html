6 步驟完成自己的 GitHub 網站

先把老師的專案複製成自己的，再修改、上傳！

注意：Fork 要在 GitHub 網站做，不是在 GitHub Desktop 裡找。老師本人不用 Fork 自己的專案。

Fork在網路上複製一份老師的專案
Clone把自己的專案下載到電腦
Commit記錄這次修改，像遊戲存檔
Push把修改上傳到 GitHub
  1. 01

    準備帳號與軟體

    註冊 GitHub 帳號，安裝 GitHub Desktop，並登入自己的帳號。

    完成：GitHub Desktop 已登入。

  2. 02

    Fork：複製老師的專案

    在瀏覽器開啟 老師的 Taiwan-Scene → 右上角 Fork → Create fork。

    完成：網址開頭變成 github.com/你的帳號/。

  3. 03

    Clone：下載到電腦

    打開 GitHub Desktop → File → Clone repository → 選自己的 你的帳號/Taiwan-Scene → Clone。

    完成：電腦裡出現 images 資料夾和 index.html。

  4. 04

    修改：換一張臺灣景點圖片

    打開剛下載的 images 資料夾，將新圖片命名為 001.jpg，取代原本的檔案。請用自己拍的或有權使用的圖片。

    完成：GitHub Desktop 的 Changes 出現 001.jpg。

  5. 05

    Commit：記錄修改

    在左下方 Summary 輸入 更換景點圖片，按 Commit to main。

    記住：Commit 像存檔，這時還沒上傳到網站。

  6. 06

    Push：上傳並檢查

    按上方 Push origin，再到自己 GitHub 的 Taiwan-Scene 網頁重新整理，檢查新圖片。

    完成：GitHub 網頁看得到更新的圖片！

加分挑戰：做出自己的旅遊網站

到自己的 GitHub 專案 → Settings → Pages → Source 選 Deploy from a branch → 選 main、/(root) → Save。

完成部署後，網站網址通常是：https://你的帳號.github.io/Taiwan-Scene/。

卡住了？先檢查這三件事

找不到 Fork？
Fork 在 GitHub 網站右上角，不在 GitHub Desktop 首頁。
Changes 沒東西？
請確認修改的是 Clone 下來的資料夾，並且有存檔。
GitHub 網頁沒更新？
Commit 後還要按 Push origin！

學生操作流程：Fork → Clone → 修改 → Commit → Push
  1. 建立自己的 GitHub 帳號，安裝 GitHub Desktop。
  2. 在此專案 GitHub 頁面點 Fork，建立自己的版本（沒有原專案寫入權限時，不能直接 Push 至教師專案）。
  3. GitHub Desktop：File → Clone repository，選擇自己 Fork 的儲存庫。
  4. 修改圖片、標題或景點資料，確認 Changes 中出現變更。
  5. 輸入 Summary，按 Commit to main，再按 Push origin。
  6. 到 GitHub 個人儲存庫確認檔案已更新，進一步設定 GitHub Pages。
